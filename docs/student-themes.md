# 학생 테마

## 대학교 테마

서울대학교(`university-snu`), 연세대학교(`university-yonsei`), 고려대학교(`university-korea`) 테마를 학생의 내 테마 화면에서 선택합니다. 기존 계정별 저장 API를 그대로 사용하므로 추가 SQL 마이그레이션은 필요하지 않습니다.

사용자가 제공한 서울대학교 교표, 연세대학교 독수리 SVG 및 원형 로고, 고려대학교 호랑이 및 방패 로고를 `public/themes/universities/`에 원본 그대로 보관합니다. 이미지는 헤더, 홈 배너, 선택 카드, 타이머, 리워드 쿠폰 및 배경 워터마크에 적용합니다. 연세대 페넌트 참고 이미지와 고려대 흑백 호랑이 이미지는 디자인 참고용이며 페이지에 직접 넣지 않습니다. 이미지 선택은 `components/UniversityEmblem.tsx`, 공통 홈 배너는 `components/UniversityBrandPanel.tsx`, 팔레트는 `app/student/student-theme.css`에서 관리합니다.

`/preview/universities`에서 로그인 없이 세 테마의 홈·타이머·사용 가능/완료 쿠폰을 비교할 수 있습니다. 홈 데이터와 쿠폰 코드는 예시이며 타이머 기록이나 실제 계정 테마를 변경하지 않습니다.

학생 상단 이름을 누르면 **내 테마**에서 기본 그린, 자이언츠 라이트(버전 1), 자이언츠 유니폼(버전 2)을 고릅니다. 이름은 일반 텍스트처럼 표시하고 화살표는 넣지 않습니다. 선택 카드는 학생 화면의 상단 헤더와 본문 배경을 간단히 보여주며, 숙제 제목 자리에는 테마 이름을 표시합니다. 적용 버튼을 눌러 저장하며, 서버 저장 실패 시 기존 테마를 유지하고 오류를 표시합니다.

테마는 학생 레이아웃에만 적용됩니다. 기본 그린의 색상은 유지하고, 그린 쿠폰에는 새 식물/학원 로고 디자인을 사용합니다. 자이언츠 테마에는 Regular/Inline 폰트, 원형 테두리 타이머, 야구 티켓 쿠폰을 적용합니다. 타이머에서만 배경 워터마크를 숨깁니다.

## 계정 저장

`/api/student-theme`은 학생 세션의 Bearer 토큰을 `client_sessions`에서 검증합니다. 학생 ID는 요청 본문에서 받지 않고 유효한 학생 세션에서만 결정합니다. 학부모·만료 세션은 거부합니다. 쓰기 요청은 동일 출처만 허용하며 응답은 캐시하지 않습니다.

설정은 Supabase Storage 비공개 버킷 `student-preferences`의 `<studentId>/theme.json`에 저장합니다. 첫 저장 시 서버가 비공개 버킷을 생성합니다. 공개 버킷에는 저장하지 않으며 클라이언트용 Storage 접근 정책을 추가하지 않습니다. 별도 SQL 마이그레이션은 필요하지 않습니다. 서버의 기존 `SUPABASE_SERVICE_ROLE_KEY` 환경 변수가 필요합니다. 키는 브라우저에 전달되지 않습니다.

기본값은 그린이며, 다른 기기에서 로그인하면 계정 설정을 다시 불러옵니다. 세션 변경 중 이전 요청 결과는 무시합니다. 브라우저의 로컬 저장만으로 저장 성공을 표시하지 않습니다.

- `/preview/giants/timer`: 타이머 체험(기록 저장 없음)
- `/preview/giants/coupons`: 자이언츠 쿠폰 예시
- `/preview/coupons`: 기본 그린 쿠폰 예시

실제 학생 타이머는 기존 서버 동기화·기록 저장 로직을 그대로 사용하며, 자이언츠 테마일 때 다이얼만 변경합니다.
