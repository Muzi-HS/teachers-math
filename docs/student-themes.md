# 학생 테마

학생 상단 이름을 누르면 **내 테마**에서 기본 그린, 자이언츠 라이트(버전 1), 자이언츠 유니폼(버전 2)을 고릅니다. 이름은 일반 텍스트처럼 표시하고 화살표는 넣지 않습니다. 선택 카드는 상단색·본문색·줄무늬·작은 로고만 표시합니다. 적용 버튼을 눌러 저장하며, 서버 저장 실패 시 기존 테마를 유지하고 오류를 표시합니다.

테마는 학생 레이아웃에만 적용됩니다. 기본 그린의 색상은 유지하고, 그린 쿠폰에는 새 식물/학원 로고 디자인을 사용합니다. 자이언츠 테마에는 Regular/Inline 폰트, 원형 테두리 타이머, 야구 티켓 쿠폰을 적용합니다. 타이머에서만 배경 워터마크를 숨깁니다.

## 계정 저장

`/api/student-theme`은 학생 세션의 Bearer 토큰을 `client_sessions`에서 검증합니다. 학생 ID는 요청 본문에서 받지 않고 유효한 학생 세션에서만 결정합니다. 학부모·만료 세션은 거부합니다. 쓰기 요청은 동일 출처만 허용하며 응답은 캐시하지 않습니다.

설정은 Supabase Storage 비공개 버킷 `student-preferences`의 `<studentId>/theme.json`에 저장합니다. 첫 저장 시 서버가 비공개 버킷을 생성합니다. 공개 버킷에는 저장하지 않으며 클라이언트용 Storage 접근 정책을 추가하지 않습니다. 별도 SQL 마이그레이션은 필요하지 않습니다. 서버의 기존 `SUPABASE_SERVICE_ROLE_KEY` 환경 변수가 필요합니다. 키는 브라우저에 전달되지 않습니다.

기본값은 그린이며, 다른 기기에서 로그인하면 계정 설정을 다시 불러옵니다. 세션 변경 중 이전 요청 결과는 무시합니다. 브라우저의 로컬 저장만으로 저장 성공을 표시하지 않습니다.

## 디자인 미리보기

- `/preview/giants`: 자이언츠 버전 1/2 비교
- `/preview/giants/timer`: 타이머 체험(기록 저장 없음)
- `/preview/giants/coupons`: 자이언츠 쿠폰 예시
- `/preview/coupons`: 기본 그린 쿠폰 예시

실제 학생 타이머는 기존 서버 동기화·기록 저장 로직을 그대로 사용하며, 자이언츠 테마일 때 다이얼만 변경합니다.
