# 학부모 문자 앱 연결

- **학생 관리 → 메시지 보내기**에서 이름을 검색하거나 학교 구분·학교·나이·반을 복수 선택하고, 원하는 학생을 체크합니다. 모바일에서는 전체 화면 창으로 열립니다. 나이는 학생관리와 같은 연 나이(현재 한국 연도 − 출생 연도 + 1)입니다.
- 표 머리글의 체크박스를 누르면 현재 검색 결과 중 발송 가능한 학생을 전체 선택하고, 다시 누르면 해당 결과만 선택 해제합니다. 일부 선택 시에는 체크박스에 부분 선택 표시가 나타납니다. 필터를 바꿔도 기존 선택은 유지되며 **모든 선택 해제**로 전체 선택을 비울 수 있습니다.
- 내용을 입력하고 일괄 전송 준비를 누르면 전체 수신 대상과 내용을 검토할 수 있습니다. 같은 번호는 중복 제거하고, 올바른 학부모 휴대폰 번호가 없는 학생은 제외합니다.
- 공지사항 상세의 **미열람 학부모에게 문자 보내기**는 창을 여는 시점의 공개 대상·읽음 기록을 다시 조회하여 미열람 학생만 보여주고 기본 선택합니다. 전체 공개와 선택 공개 모두 지원하며 비공개 공지에는 버튼이 없습니다.
- 관리자는 전체 학생, 선생님은 기존 `teacher_student_directory` RPC가 반환한 담당 학생만 조회합니다. 조교·학생·학부모는 사용할 수 없습니다.

## 실제 전송

학생관리의 메시지 창에서는 **받는 사람 → 학부모에게 / 학생에게**를 선택합니다. 표의 연락처·선택 가능 여부·최종 수신번호가 해당 대상에 맞춰 변경됩니다. 대상 전환 시 학생 선택은 초기화되고 작성 내용과 필터는 유지됩니다. 공지사항 메시지는 학부모 전용이며 대상 전환 버튼이 없습니다.

휴대폰에서 문자 앱 열기를 누르고 수신번호·내용을 확인한 뒤 문자 앱의 전송 버튼을 누릅니다. 본인 번호와 통신요금제가 적용됩니다. 문자 앱의 개별 발송 설정을 확인하여 학부모끼리 번호가 공개되는 그룹 대화를 피하세요.

여러 수신번호와 본문 자동 입력은 OS·브라우저·문자 앱에 따라 지원이 다르고 수신자 수 제한도 있습니다. 실제 사용하는 휴대폰에서 소수의 테스트 번호로 확인해야 합니다. PC에서는 별도 휴대폰 연동이 필요합니다. 웹은 문자 앱 실행이나 실제 발송 성공 여부를 확인하지 않으며 발송완료 이력을 기록하지 않습니다.

iOS의 여러 수신번호는 `sms://open?addresses=번호1,번호2&body=...` 형식으로 전달합니다. 수신번호 중복 제거 후 한 개만 남으면 기존 단일 수신자 링크를 사용합니다. 참고: https://sethmlarson.dev/sms-urls (실기기 테스트 필요).

별도 SQL 마이그레이션이나 문자 API 키는 필요하지 않습니다. 기존 학생 연락처·담당 학생 조회·공지 대상 및 읽음 테이블을 사용합니다.
